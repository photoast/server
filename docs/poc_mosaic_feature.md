# 프로젝트: PhotoToast 실물 참여형 모자이크 시스템 PoC

이 문서는 관리자가 모자이크 도안을 설정하고, 유저가 사진을 찍어 특정 위치에 참여하는 전체 프로세스를 구현하기 위한 기술 명세서이다.

## 1. 관리자 기능 (Admin Flow: Setup & Preview)
관리자는 행사를 시작하기 전 모자이크의 뼈대를 설정한다.
- **이미지 업로드:** 모자이크의 최종 완성본이 될 '타겟 이미지'를 업로드한다.
- **그리드 설정:** 가로(X) x 세로(Y) 픽셀(타일) 개수를 입력받는다. (기본값: 20x15)
- **도안 분석 및 미리보기:** - 업로드된 이미지를 설정된 그리드로 쪼개어 각 칸의 평균 RGB 값을 계산한다.
  - 화면에 '분석된 도안 미리보기'를 렌더링하여, 실제 모자이크로 구현되었을 때의 시각적 느낌을 확인한다.

## 2. 클라이언트 기능 (Client Flow: Participation)
유저는 현장 키오스크에서 아래 과정을 거친다.
- **위치 선택:** 관리자가 설정한 그리드 맵(미니맵)에서 아직 비어있는 칸을 터치하여 선택한다. (예: C-14)
- **사진 업로드:** 유저가 촬영한 사진(더미 이미지)을 시스템에 넣는다.
- **합성 미리보기:** 유저가 선택한 위치에 맞춰 '인화용 최종 결과물'을 실시간으로 합성하여 화면에 보여준다.

## 3. 최종 합성 및 렌더링 로직 (Canvas API)
결과물은 1200x1800(4x6 인치) 해상도의 단일 이미지로 렌더링되어야 하며, 구성은 다음과 같다.

### A. 메인 사진 영역 (Top 1200x1200px)
- 유저가 업로드한 원본 사진을 필터 없이 선명하게 배치.

### B. 모자이크 타일 영역 (Bottom Left 600x600px)
- **색상 보정(Tinting):** 유저가 선택한 좌표의 타겟 평균 RGB 색상을 가져와, 유저 사진 위에 15~20% 농도로 덮어씌움 (Overlay).
- **테두리(Border):** 타일 테두리에 타겟 RGB 색상으로 두꺼운 선(Stroke)을 그려 시각적 일체감을 부여함.
- **좌표 텍스트:** 타일 하단에 유저가 선택한 좌표(예: [C-14])를 텍스트로 박아 넣음.

### C. 안내 영역 (Bottom Right 600x600px)
- 이벤트 로고나 럭키드로우용 QR 코드가 들어갈 더미 영역.

## 4. 구현 요청사항
- React와 HTML5 Canvas API를 사용해 단일 페이지 앱으로 구현해 줘.
- 상단에는 '관리자 설정 섹션', 하단에는 '유저 참여 및 결과물 미리보기 섹션'이 구분되어 있어야 함.
- 파일 업로드 및 그리드 변경 시 모든 Canvas 연산은 실시간으로 반영되어야 함.
